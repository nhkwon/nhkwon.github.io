# Excel data

Upload the data workbook here as `site-data.xlsx`.

Supported sheets:

- `metrics`: columns `key`, `value`
- `publications`: columns `title`, `authors`, `venue`, `year`, `citations`, `type`, `doi`, `paperUrl`, `indexType`, `impactFactor`, `percentile`, `topPercent`

The current workbook format is also supported:

- `전체-ver1-IF_SCI`: SCI/SCIE/ESCI journal papers
- `전체-ver1-IF_국내`: domestic/KCI journal papers
- `수상실적`: awards
- `학술발표`: conference presentations
